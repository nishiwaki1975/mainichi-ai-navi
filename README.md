# まいにちAIナビ（GitHub移行用エクスポート）

Muse内の試作品「まいにちAIナビ」の保存データを書き出し、GitHub Pages で
公開できる静的サイト形式に再構成したものです。
**このフォルダ自体はまだ公開されていません。** リポジトリ作成・公開・定期実行の
有効化には、所有者の承認が必要です。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体（静的ページ）。`data/portal.json` を読み込んで4カテゴリを表示 |
| `data/portal.json` | 表示データ（天気・ニュース・お出かけ・お得）。取得日時と出典を含む |
| `scripts/fetch_update.py` | データ取得スクリプト。気象庁公式JSONとNHK RSSを取得し `portal.json` を更新。失敗時は前回データを保持し `stale: true` を立てる |
| `.github/workflows/update-data.yml` | GitHub Actions のスケジュール定義（下書き）。JST 7時/12時/18時に天気+ニュース、7時にお出かけ確認、8時にお得確認 |

## 役割分担

- **GitHub Pages**: サイトの公開（静的配信）
- **GitHub Actions**: 天気・ニュースの定期取得と `portal.json` の自動コミット
- **Muse**: サイトの設計・改修、お出かけ／お得情報の内容確認と差し替え、障害時の調査
- **気象庁 / NHK / 各公式サイト**: 一次情報の提供

## ニュースについて（情報源の利用規約への対応）

NHK・消費者庁・内閣府などの RSS は、各機関の規約で「再配信・再提供は
認められていない」ことが明記されています。そのため公開サイトでは
報道機関の RSS を転用せず、公共データ利用規約（PDL1.0）の対象で
出典明示により利用できる **政府広報オンライン** の発表を掲載します。
要約はフィードの説明文を整形したものです（AIによる言い換えではありません）。
天気は気象庁の公式データ（同じくPDL1.0）を、出典明示と「加工して作成」の
注記つきで利用しています。NHKニュースへはリンクのみを掲載しています。

## 承認後に実施する導入手順

1. GitHub で新規リポジトリを作成（例: `mainichi-ai-navi`、Public）
   ※ GitHub Free で Pages を使うには公開リポジトリが必要
2. このフォルダの中身をリポジトリへ push
3. リポジトリの Settings → Pages で公開元を `main` ブランチに設定
4. 公開URL（`https://<ユーザー名>.github.io/mainichi-ai-navi/`）で表示確認
5. Actions タブで `update-data` ワークフローを手動実行し、コミットが作られることを確認
6. Facebook でURLを共有

## 制約・注意点

- Pages の上限: サイト容量1GB、月間転送量の目安100GB（ソフト制限）。本サイトは十分に小さい
- Actions のスケジュールは UTC 指定で、混雑時に遅延することがある。最短間隔は5分
- スケジュールはデフォルトブランチでのみ動作する。60日間リポジトリに動きがないと
  スケジュールが無効化される場合があるが、本構成は毎日コミットが発生するため該当しにくい
- 公開リポジトリのため、`portal.json` を含む全ファイルが誰でも閲覧できる。
  個人情報やAPIキーを絶対に置かないこと
- ワークフローの権限は `contents: write` のみに限定済み。外部アクションは公式の
  `actions/checkout` と `actions/setup-python` のみ使用
- 天気・ニュース以外の情報（イベント、セール）は自動で内容を書き換えない。
  出典URLの到達確認のみ自動化し、内容の差し替えは確認後に行う（誤情報防止）
