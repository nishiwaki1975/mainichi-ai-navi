# まいにちAIナビ

天気・ニュース・週末のお出かけ情報・暮らしのお得情報を1か所で確認できる、
日本語の生活情報ポータルサイトです。**運用中**です。

- 公開サイト: https://nishiwaki1975.github.io/mainichi-ai-navi/
- リポジトリ: https://github.com/nishiwaki1975/mainichi-ai-navi

このサイトは、Museを活用して制作し、GitHub Actionsで定期更新しています。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体（静的ページ）。`data/portal.json` を読み込んで4カテゴリを表示。OGP設定済み（`ogp.png`） |
| `data/portal.json` | 表示データ（天気・ニュース・お出かけ・お得）。取得日時と出典を含む |
| `ogp.png` | SNS共有時のサムネイル画像（1200×630） |
| `scripts/fetch_update.py` | データ取得スクリプト。気象庁公式JSONと政府広報オンラインRSSを取得し `portal.json` を更新。失敗時は前回データを保持し `stale: true` を立てる |
| `.github/workflows/update-data.yml` | GitHub Actions のスケジュール定義（Asia/Tokyo指定で稼働中） |

## 自動更新スケジュール（日本時間）

| 時刻 | 更新対象 |
|---|---|
| 毎日 7:00 | 天気・ニュース・お出かけ（出典確認） |
| 毎日 8:00 | お得情報（出典確認） |
| 毎日 12:00 / 18:00 | 天気・ニュース |

更新対象は、実行が遅延した場合でも「予定されていたスケジュール（cron式）」を
もとに決まります。手動実行（workflow_dispatch）の場合は全カテゴリが対象です。

お出かけ・お得情報は、終了日（`end_date`）を過ぎたアイテムが自動で非表示に
なります（画面側の表示制御と、取得スクリプト側の除去の両方で実施）。

## 役割分担

- **GitHub Pages**: サイトの公開（静的配信）
- **GitHub Actions**: 天気・ニュースの定期取得と `portal.json` の自動コミット
- **Muse**: サイトの設計・改修、お出かけ／お得情報の内容確認と差し替え、障害時の調査
- **気象庁 / 政府広報オンライン / 各公式サイト**: 一次情報の提供

## ニュースについて（情報源の利用規約への対応）

NHK・消費者庁・内閣府などの RSS は、各機関の規約で「再配信・再提供は
認められていない」ことが明記されています。そのため公開サイトでは
報道機関の RSS を転用せず、公共データ利用規約（PDL1.0）の対象で
出典明示により利用できる **政府広報オンライン** の発表を掲載しています。
要約はフィードの説明文を整形したものです（AIによる言い換えではありません）。
天気は気象庁の公式データ（同じくPDL1.0）を、出典明示と「加工して作成」の
注記つきで利用しています。NHKニュースへはリンクのみを掲載しています。

## 制約・注意点

- Pages の上限: サイト容量1GB、月間転送量の目安100GB（ソフト制限）。本サイトは十分に小さい
- Actions のスケジュールは混雑時に数分〜十数分遅延することがある
- スケジュールはデフォルトブランチでのみ動作する。毎日コミットが発生するため、
  60日間無活動によるスケジュール無効化には該当しにくい
- 公開リポジトリのため、`portal.json` を含む全ファイルが誰でも閲覧できる。
  個人情報やAPIキーを絶対に置かないこと
- ワークフローの権限は `contents: write` のみに限定済み。コミット対象も
  `data/portal.json` のみを明示している。外部アクションは公式の
  `actions/checkout` と `actions/setup-python` のみ使用
- 天気・ニュース以外の情報（イベント、セール）は自動で内容を書き換えない。
  出典URLの到達確認のみ自動化し、一部でも確認できない場合は「未確認」と
  分かる表示になる。内容の差し替えは確認後に行う（誤情報防止）
- Facebook で共有した際の表示は、Facebook側のキャッシュにより反映まで
  時間がかかる場合がある（Sharing Debugger で再取得が可能）
